# v0.2.2 — 新 App 图标

## What's Changed

### 🎨 图标

* **全新 App 图标**：换掉原来的 3D 卡通头像，改为扁平的时间轴标记——三条任务行，
  其中一条用琥珀色圆点标记为「当前」，旁边一颗星芒代表 AI 分析。配色沿用原图标的
  浅蓝 → 薰衣草紫，App 在 Dock 和访达里看起来仍是同一个产品。

* macOS / Windows / Android / iOS 四套图标资源全部重新生成（`bun tauri icon`）。
  资源自带超椭圆（squircle）遮罩与透明四角——macOS 不会自动裁切 App 图标，这一步
  必须由资源自己完成；同时资源本身不带投影，避免系统再叠一层。
