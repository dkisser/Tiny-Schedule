# v0.2.0 — 桌面壳从 Electron 迁到 Tauri

## What's Changed

### 🔄 Breaking Changes

* **桌面壳从 Electron 换成 Tauri 2**，Rust 只做薄壳。安装包从 **189 MB 降到 11.7 MB**
  （arm64，Intel 版 11.9 MB），缩小约 94%。macOS 上渲染层改用系统 WKWebView，不再
  捆绑 Chromium + Node 运行时。

  **数据零迁移**：新老版本读同一个 `~/Library/Application Support/@tiny-schedule/app/`
  目录，同一份 `data.json`、同一把 AES-256-GCM key。升级后所有任务、项目、标签、
  计时历史原样在位，直接打开即可，无需任何导入步骤。

* **Electron 版已从仓库删除**。`packages/app` 包与其构建链（electron-vite、
  electron-builder）一并移除，仓库只保留 Tauri 实现。`packages/shared`（契约与领域
  逻辑）零改动。

* **`bun run dev` / `build` / `release` 现在都指向 Tauri**，不再启动 Electron 开发
  环境。开发环境需要 Rust 工具链（`cargo` + Xcode Command Line Tools）。

### 🐛 Fixes

* **Dock 图标右键退出不再丢失计时历史**（部分修复，见下方"已知缺口"）。

### 📚 Documentation

* docs: add ADR 0003 — 桌面壳从 Electron 迁到 Tauri，Rust 只做薄壳
* docs: add Tauri 迁移功能 parity 验收清单（35 个 invoke + 11 个推送通道逐条对照）

## 已知缺口

**从 Dock 图标右键 → 退出，有计时在跑时不会弹退出确认框**，这段尚未结算的时长会
丢失。

- **范围仅限 Dock 右键**。Cmd+Q 与菜单栏"退出"都已覆盖，会正常弹确认。
- **数据不会损坏**。`activeTimer` 每次变更都持久化，退出丢的只是这次会话尚未结算
  的那几十秒，下次启动会读回并继续计时。已写下的任务历史不受影响。
- **原因是上游未修**。tauri#9198 自 2024-03-16 起 open，修复它的 tao#1003 尚未合入。
  在本仓库关掉它需要 `unsafe` 覆写 `NSApplication` delegate 或 fork tao，代价与收益
  不匹配（单窗口工具，Cmd+Q 是主流退出手势）。详见
  `packages/tauri-app/src-tauri/src/close.rs` 的模块文档与
  [parity 清单](../tauri-migration-parity.md#_1-dock-右键退出绕过退出确认唯一缺口)。

## 技术说明

架构采用**薄 Rust 壳**：业务逻辑（数据 CRUD、AI 调用、导入导出、迁移）全部留在
webview 里的 TypeScript 里，Rust 只做系统胶水——窗口、通知、文件对话框、
alwaysOnTop、更新检查、spawn event-helper，以及一座 SSE 桥。

这座 SSE 桥是必要的：OpenAI 兼容 API 一般不发 CORS 头，webview 里的裸 `fetch`
调不通，所以 AI 日报与 chat 的流式响应由 Rust 侧 reqwest 接收、按事件推给前端。

macOS 日历写入用的 event-helper（Swift CLI）随 Electron 包一起搬进了
`packages/tauri-app/`，改由 Rust `Command` spawn。

功能 parity 已逐条验收：35 个 invoke 与 11 个推送通道全部覆盖，证据见
[parity 验收清单](../tauri-migration-parity.md)。
