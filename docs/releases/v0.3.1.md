# v0.3.1 — 子任务勾选修复

## What's Changed

### 🐛 这一版修掉的问题

* **子任务勾不上「完成」**：在任务详情面板里点子任务的复选框，勾上会立刻弹回未勾选状态；
  反过来取消勾选，却会把子任务标成完成——每次点击都在做与意图相反的事。

  完成流程统一经过 `requestComplete`，它读传入任务**当前**的 `isDone` 来判断这次该往哪个
  方向切换。任务卡片传的是切换前的任务，方向正确；子任务那处传的是切换之后的对象，于是
  勾选走进了「取消完成」分支、写回 `isDone: false`。已改为与卡片传同一个对象，方向判定
  与 `doneAt` 的清理由 `requestComplete` 自己负责。
