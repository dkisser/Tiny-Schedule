# v0.3.2 — 隐藏定时任务入口与工程清理

## What's Changed

### ✨ Features

* **暂时隐藏定时任务的面板入口** (251c7c3, #32)
  功能不删除，只是从侧栏隐藏那一行导航项。新增 `SHOW_SCHEDULED_TASKS_ENTRY` 单点开关
  （当前为 `false`）；数据模型、调度器、列表页、详情面板、IPC 契约、运行历史全部保留。
  调度器在 `bridge/bootstrap.ts` 中无条件起跑，已配置的定时任务照常到点触发、照常落
  运行记录、照常发系统通知——变的只是人看不到入口，因而暂时也无法新建或编辑。
  恢复入口只需把开关改回 `true`，无需数据迁移。

### 🔧 Maintenance

* **移除 graphify 集成与相关描述** (aeee956)
  用 graphify 官方项目级卸载命令清除 `CLAUDE.md` 与 `.claude/settings.json` 里的
  PreToolUse hook，摘掉 `AGENTS.md` 的 `## graphify` 段（保留「UI 规范」段），
  并修掉 README 中指向已删除 `CLAUDE.md` 的两处悬空链接。
* **同步 Cargo.lock 中 tauri-app 的版本号** (2bf2e62)
  `Cargo.lock` 里 tauri-app 仍是 0.2.2，此次与 `Cargo.toml` 对齐。
