# 项目只归档，不删除

项目（Project）不提供删除功能，归档是项目唯一的终结方式。背景：想法（Idea）升级为"验证中"时会关联一个专属项目，而想法的验证闭环（给出结论）由"项目归档"触发——如果项目可以被直接删除，用户就能绕过闭环，让验证中的想法永远悬空。删除入口的存在本身是个后门，所以我们选择移除它，而不是给删除路径也加一个闭环弹窗。

## Considered Options

- **删除时也弹闭环弹窗**：被否决。两个终结入口（归档/删除）都要维护闭环逻辑，且"删除"语义过重——归档已能表达"这个项目不做了"，任务在归档后仍可查看。
- **删除时自动把想法转为"待结论"**：被否决。同样留了后门：想跳过结论的人会养成删项目的习惯。

## Consequences

- 侧栏项目行不再有删除按钮；`project:delete` IPC 通道保留但 UI 不暴露。
- 想"彻底清掉"一个项目的用户只能归档。归档项目在侧栏"已归档 (n)"折叠分组中始终可见、可恢复，数据不会丢。
